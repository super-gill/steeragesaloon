# Steerage & Saloon

Version 0.39.8 (6 October 2026). Stage: **active**, building towards 0.40.0.

A real-time shipping line management game. You run the Morven Line from its Glasgow head office from January 1900, with one elderly emigrant ship and no end date (in this world the liner trade never declined, so later decades are invented): open passenger lines and cargo trades, buy, build, refit and retire ships, hire masters, build up a shore establishment and head-office departments, and survive the rate wars of the emigrant years, the Combine, the 1912 disaster, the Great War and the boom that follows it, the US immigration quotas, the 1926 coal strike and the Depression. A share market runs alongside, where the Line can take stakes in its rivals and take them over, float itself, and play rough: raids, tenders, proxy fights, shorts and bear raids.

1900 to 1939 is written and being balanced; the milestone is 0.40.0, and 1.0 is the game complete to the present day (`docs/design/direction.md`).

## Playing

A static browser game with no build step: open `index.html`, or serve the folder. The game saves itself in the browser, so each site or folder it is opened from keeps its own save; save codes (Company tab) carry a game anywhere. What's new in each release is in the game (Menu, What's new and coming next) and in `docs/process/changelog.md`.
